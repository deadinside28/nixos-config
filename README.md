# ❄️ NixOS Gaming Config

Моя персональная конфигурация **NixOS**, заточенная под максимальную производительность, гейминг и удобный тайлинг. 

Построена на базе **Flakes** и **Home Manager**. Окружение рабочего стола управляется кастомной оболочкой на базе **Hyprland**, конфигурация которого написана на **Lua**.

## 💻 Мое железо
* **CPU:** AMD Ryzen 7 5700X3D
* **GPU:** AMD Radeon RX 7800 XT
* **Мониторы:** 
  * 🖥️ LG Ultrawide (2560x1080 @ 100Hz) — основной
  * 🖥️ Acer (1920x1080 @ 100Hz) — дополнительный

## 🚀 Ключевые фичи и технологии

* **Ядро:** `linuxPackages_cachyos` (подключено через репозиторий [Chaotic-Nyx](https://github.com/chaotic-cx/nyx)). Планировщик `sched-ext` (scx_rustland) для максимальной отзывчивости системы и высокого FPS.
* **Window Manager:** [Hyprland](https://hyprland.org/). Правила окон, бинды и настройки вынесены в модульную структуру на **Lua** (интеграция DMS).
* **Гейминг:** Нативный Steam, Gamescope, Gamemode, кастомные Proton (через ProtonPlus/Heroic).
* **Стриминг:** Автозапуск Sunshine (Moonlight) для трансляции игр на другие устройства с открытыми портами в Firewall.
* **Автоматизация даунвольта:** При каждой загрузке systemd-сервис запускает кастомный Python-скрипт (`scripts/ruv.py`), который применяет Curve Optimizer (-25) для процессора Ryzen напрямую через `ryzen_smu`.
* **Управление пакетами:**
  * Системные пакеты — Nix
  * Пользовательские приложения — Home Manager
  * Декларативный Flatpak — через `nix-flatpak`
  * AppImage — через `appimage-run` (настроен `systemd`-таймер, который автоматически подтягивает `.desktop` файлы и иконки AppImage-программ в меню приложений).
* **Терминал:** Kitty + оболочка Fish + кастомный вывод Fastfetch.
* **Кастомизация:** Живые обои напрямую из Steam Workshop через `linux-wallpaperengine`.

## 🖥️ Логика мониторов и воркспейсов (Hyprland)

В системе жестко прописана логика распределения рабочих столов на два монитора. Это позволяет всегда знать, где находится нужное приложение, и не терять их из виду во время игры.

**Основной монитор (LG Ultrawide, HDMI-A-1):**
* Отведен под воркспейсы **с 1 по 4**, а также специальный воркспейс **5 (Gaming)**.
* 🎮 Воркспейс **5** — эксклюзивный игровой экран. Сюда автоматически отправляются все процессы с флагом `game`, окна Steam, Battle.net и Gamescope.
* Навигация по этим воркспейсам осуществляется клавишами `SUPER + [1, 2, 3, 4, G]`.

**Дополнительный монитор (Acer, HDMI-A-2):**
* Отведен под воркспейсы **с 6 по 9**. Навигация — `SUPER + [F1, F2, F3, F4]`.
* На эти воркспейсы настроен жесткий автозапуск (Авто-тайлинг):
  * **6 (F1):** Discord
  * **7 (F2):** Telegram
  * **8 (F3):** YouTube Music
  * **9 (F4):** Главное окно Steam

## ⌨️ Горячие клавиши (Keybindings)

Главная клавиша-модификатор (MainMod) — **SUPER (Windows)**.

### 🚀 Быстрый запуск (Launchers)
| Хоткей | Действие |
| :--- | :--- |
| `SUPER + W` | Веб-браузер (Google Chrome) |
| `SUPER + T` | Терминал (Kitty) |
| `SUPER + E` | Файловый менеджер (Nautilus) |
| `SUPER + C` | Редактор кода (VS Code) |
| `SUPER + Space` | 🔍 Глобальный поиск (через DMS) |

### 🛠 Утилиты и меню (Интеграция DMS)
| Хоткей | Действие |
| :--- | :--- |
| `SUPER + V` | Менеджер буфера обмена (Clipboard) |
| `SUPER + M` | Диспетчер задач (Processlist) |
| `SUPER + S` | Быстрые настройки (Settings) |
| `SUPER + N` | Центр уведомлений (Notifications) |
| `SUPER + Y` | Выбор обоев (Dankdash wallpaper) |
| `SUPER + TAB` | Обзор всех окон (Overview) |
| `SUPER + SHIFT + Q` | ⚡ Меню выключения (Powermenu) |
| `SUPER + ALT + L` | 🔒 Заблокировать экран |

### 📸 Скриншоты и Запись экрана (AV1, 60 FPS)
*Используются нативные Wayland-утилиты (Grim, Slurp) и GPU Screen Recorder.*
| Хоткей | Действие |
| :--- | :--- |
| `SUPER + SHIFT + S` | Скриншот выделенной области (в буфер + уведомление) |
| `SUPER + SHIFT + A` | Скриншот всего экрана |
| `SUPER + SHIFT + D` | Скриншот активного окна |
| `ALT + F9` | 🔴 Начать/Остановить запись экрана **БЕЗ** микрофона |
| `ALT + F10` | 🎙️ Начать/Остановить запись экрана **С** микрофоном |

### 🪟 Управление окнами
| Хоткей | Действие |
| :--- | :--- |
| `SUPER + Q` | Закрыть окно |
| `SUPER + Escape` | "Убить" зависшее окно (hyprctl kill) |
| `SUPER + ALT + Space` | Переключить окно в плавающий режим (Float) |
| `SUPER + F` | Полноэкранный режим (Fullscreen) |
| `SUPER + D` | Максимизировать окно, оставив панель (Maximize) |
| `SUPER + J` | Изменить направление разделения экрана (Toggle split) |
| `SUPER + Стрелки` | Перемещение фокуса между окнами |
| `SUPER + SHIFT + Стрелки` | Переместить окно в сетке |
| `ALT + Tab` | Переключение между окнами (Cycle) |
| `SUPER + ЛКМ / ПКМ` | Перетаскивание / Изменение размера плавающего окна |

### 🗂 Навигация по воркспейсам
* **Переключение:** `SUPER + [1-4, G]` (Основной монитор), `SUPER + [F1-F4]` (Второй монитор).
* **Перемещение окна:** `SUPER + SHIFT + [1-4, G, F1-F4]` — отправить активное окно на соответствующий воркспейс.
* **Соседние экраны:** `SUPER + CTRL + Стрелки Влево/Вправо` — перелистывание воркспейсов на текущем мониторе.
* **Мышь:** Листать воркспейсы можно скроллом мыши при зажатом `SUPER` или `SUPER + CTRL`.

## 📦 Как применить эту конфигурацию

> **Внимание:** Конфигурация содержит настройки под конкретное железо (UUID дисков в `disks.nix`, скрипты под Ryzen). Перед использованием на другой машине обязательно отредактируйте `hardware-configuration.nix` и `disks.nix`.

Так как это системная конфигурация, она хранится в стандартной директории `/etc/nixos`.

```bash
# 1. Клонируем репозиторий (с правами root)
sudo git clone https://github.com/deadinside28/nixos-config.git /etc/nixos
cd /etc/nixos

# 2. Обновляем lock-файл (опционально)
sudo nix flake update

# 3. Применяем конфигурацию системы
sudo nixos-rebuild switch --flake /etc/nixos#nixos
