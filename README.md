# ❄️ NixOS Gaming Config

Моя персональная конфигурация **NixOS**: игровой десктоп на **Hyprland** и собственной оболочке **Pixel Shell** (Quickshell, Material 3 в духе режима рабочего стола Pixel и Aluminium OS), который по ощущениям работает как цельное окружение рабочего стола, а не как набор тайлинга и панелек. Шрифты, цвета, курсор, диалоги выбора файлов и анимации одинаковые везде — в нативных приложениях, Flatpak, cpak и AppImage.

Всё описано декларативно: **Flakes** + **Home Manager**, конфиг Hyprland написан на **Lua**. Внешний вид задаётся в одном месте (`flake.nix`) и разъезжается по всей системе сам.

## 💻 Моё железо
* **CPU:** AMD Ryzen 7 5700X3D
* **GPU:** AMD Radeon RX 7800 XT
* **Мониторы:**
  * 🖥️ LG Ultrawide (2560x1080 @ 100Hz) — основной
  * 🖥️ Acer (1920x1080 @ 100Hz) — дополнительный

## 🎯 Идея: одна точка правды

Всё, что может отличаться, задаётся в одном месте и прокидывается во все модули:

* `username` в `flake.nix` — имя пользователя нигде больше не зашито;
* `configDir` в `flake.nix` — где лежит этот flake (по умолчанию `~/nixos-config`): его правит и пересобирает оболочка;
* `appearance` в `flake.nix` — шрифт интерфейса и его начертание, моноширинный шрифт, кегли, курсор;
* `hosts/<имя>/host.nix` — особенности конкретной машины: мониторы и их воркспейсы, видеокарта AMD, андервольт. Имя папки — это имя хоста.

```nix
appearance = {
  uiFont = "Google Sans";
  uiFontStyle = "Medium";   # Regular / Medium / Bold
  uiFontSize = 12;
  monoFont = "JetBrainsMono Nerd Font";
  monoFontStyle = "Medium";
  monoFontSize = 12;
  termFontSize = 14;
  cursorTheme = "Adwaita";
  cursorSize = 24;
};
```

Поменял строчку — после пересборки шрифт или курсор меняется в GTK, Qt, Flatpak, cpak, AppImage, терминале и на экране входа одновременно. Цвета, иконки и светлая/тёмная тема — забота оболочки: они меняются в её «Настройках» и тоже доходят до всех.

## 🚀 Возможности

### ⚙️ Система и производительность
* **Ядро:** `linuxPackages_cachyos` из [Chaotic-Nyx](https://github.com/chaotic-cx/nyx) + планировщик `sched-ext` (scx_rustland) для отзывчивости и высокого FPS.
* **Андервольт:** при каждой загрузке и после сна systemd-сервис запускает `scripts/ruv.py`, который выставляет Curve Optimizer (-25) через `ryzen_smu`.
* **Видеокарта:** LACT для кулеров и частот, разблокированный `ppfeaturemask`.
* **Тихая загрузка:** Plymouth с логотипом материнской платы, без текстовых логов.

### 🪟 Рабочий стол
* **[Hyprland](https://hyprland.org/) 0.56** с конфигом на Lua и лентой окон (`scrolling`-layout): окна выстраиваются в горизонтальную ленту, которая прокручивается.
* **Режимы окон без выхода из сессии:** Лента, Мозаика, Главное окно, Смешанный (тайлинг, но выбранные приложения плавают) и Плавающие — общий для всех рабочих столов и свой для отдельного стола. Переключаются в «Настройки → Окна и тайлинг», плиткой «Окна» в шторке и `Super + Shift + Пробел` (текущий стол). Уже открытые окна перекладываются сразу.
* **Редактор меню приложений** («Настройки → Меню приложений»): папки в лаунчере, свои названия и значки, скрытие без удаления программы, ключевые слова, аргументы, переменные окружения, рабочая папка, запуск в терминале и свои команды. Правки лежат поверх `.desktop` и переживают обновление пакетов; у одноимённых приложений из разных источников (Nix, Flatpak, AppImage…) подписан источник.
* **«Память»** («Настройки → Память»): чем занят диск — система и сохранённые версии, Flatpak и их данные, кеш, корзина, домашняя папка; размеры приложений (у Nix — сам пакет и отдельно замыкание с общими зависимостями), очистка кеша и сброс данных только там, где известно, где программа их хранит. Настройки Home Manager и запущенные приложения не трогаются.
* **«Магазин»** (отдельное окно, `pixel-shell store open`): общий поиск по Nixpkgs, Chaotic-Nyx и Flatpak. Пакеты Nix ищутся в тех же ревизиях, что во `flake.lock`, по локальному индексу — установка ровно той версии, из которой собирается система, без обновления входов. Установка и удаление меняют `system.json` и применяются пересборкой в фоне; «Установлено» появляется только после успешного применения. Есть разделы «Установлено», «Обновления» (система — отдельно от установки) и «История».
* **Pixel Shell** (`modules/shell`) — своя оболочка на [Quickshell](https://quickshell.org): панель задач, лаунчер, быстрые настройки, уведомления, обзор, буфер обмена, экран блокировки, агент polkit и приложение «Настройки». Подробнее — ниже. Вход — greetd с автологином.
* **Анимации Material 3 Expressive, как на Pixel:** пружины пересчитаны из токенов Android (`ExpressiveMotionTokens`). Окна появляются без «дребезга» в конце, воркспейсы листаются по вертикали.
* **Перетаскивание файлов между воркспейсами** (модуль оболочки `dndSpring`, подробнее ниже).
* **Прозрачность и размытие** окон, полноэкранные остаются непрозрачными.

### 🎨 Единый вид для всех приложений
* **Шрифт Google Sans** (системный шрифт Pixel) начертанием Medium во всей системе. Правило fontconfig подменяет «обычное» начертание на выбранное, поэтому среднежирный текст получают и GTK, и Qt, и Chrome, и Electron, и Flatpak.
* **Qt через GTK:** Qt-приложения берут шрифт, иконки и палитру из GTK — отдельный qt6ct не нужен.
* **Flatpak** видит темы, иконки, шрифты, настройки GTK/Qt и курсор хоста — только на чтение. Лишних прав приложения не получают: к файлам они ходят через общий диалог, а точечные разрешения можно дать во Flatseal.
* **Совместимость с FHS:** `/usr/share/fonts`, `/usr/share/icons` и `/usr/share/themes` смонтированы из системы — AppImage, Steam, OnlyOffice и прочий софт «не для NixOS» находят шрифты и иконки там, где привыкли.

### 📂 Одинаковые диалоги выбора файлов
Везде открывается один и тот же хостовый GTK-диалог через xdg-desktop-portal:
* **нативные GTK3/GTK4 и Qt-приложения** — через переменные сессии;
* **Flatpak** — через портал;
* **cpak** — политика в `modules/cpak-policy.nix` сама выдаёт всем приложениям право на хостовый диалог. Она срабатывает при входе и при каждой установке или обновлении приложения;
* **AppImage** — через шим `appimage-run`, через который проходят все ярлыки.

### 📦 Пакеты и форматы приложений
* **Nix** — системные пакеты, **Home Manager** — пользовательские настройки.
* **Flatpak** декларативно через `nix-flatpak`, с еженедельным автообновлением.
* **[cpak](https://github.com/Containerpak/cpak)** — приложения в контейнерах, с общей политикой для всех.
* **AppImage** запускаются напрямую, как на любом обычном дистрибутиве: `chmod +x` и `./образ.AppImage` — или двойным щелчком в «Файлах», права выставятся сами. Загрузчик даёт `nix-ld`, рантайм монтирует себя через FUSE. Ничего не распаковывается и не кэшируется. Библиотеки, которые образы ожидают от системы, — тот же набор, что даёт штатный `appimage-run`. Если образу всё же чего-то не хватает, библиотеку дописывают в `programs.nix-ld.libraries` (найти можно через `nix-locate`).
* **Distrobox и Docker** (в том числе для WinBoat).

### 🗂 Приложения
* **Файловый менеджер Nemo** с превью (`nemo-preview`); «Открыть в терминале» открывает Kitty. Есть расширение для AppImage: в контекстном меню есть «Добавить в меню приложений» и «Убрать из меню приложений». Ярлык с иконкой и описанием берётся из самого образа, а образ остаётся на месте.
* **Zed** — редактор кода.
* **btop поверх экрана** (`SUPER + M` или `SUPER + SHIFT + Esc`): процессор, видеокарта AMD, память, сеть и процессы в выезжающем окне на мониторе с фокусом. Цвета берёт из терминала, то есть из обоев.
* Qalculate!, Celluloid, Papers, Baobab, Loupe, GNOME Text Editor, GNOME Calendar, OnlyOffice, qBittorrent, Google Chrome, Telegram, YouTube Music.
* **Терминал:** Kitty + Fish + Fastfetch (в терминалах VS Code и Zed Fastfetch не запускается).
* **Живые обои** из Steam Workshop через `linux-wallpaperengine` — выбираются прямо в «Настройки → Обои и стиль».

### 🎮 Гейминг и стриминг
* Steam (с сессией Gamescope), Gamemode, MangoHud, Lutris, Heroic, ProtonPlus, Protontricks.
* **Sunshine** стартует автоматически: трансляция игр в Moonlight, порты в брандмауэре открыты, устройства находятся в сети через Avahi (MoonDeck).
* **Steam Remote Play** на Wayland: Steam запускается с `-pipewire` и захватывает экран через портал.
* **Запись экрана** через GPU Screen Recorder в AV1, 60 FPS.

## 📱 Pixel Shell

Оболочка написана с нуля на Quickshell вместо DMS и выглядит как режим рабочего стола Pixel / Aluminium OS: Material 3 Expressive, Google Sans, значки Material Symbols, цвета из обоев (matugen).

* **Панель задач** снизу: кнопка лаунчера-кольцо, точки воркспейсов, закреплённые и запущенные приложения по центру (индикатор-таблетка под активным), трей, счётчик уведомлений и «таблетка» статуса с сетью, Bluetooth, звуком и часами. ПКМ по значку — меню: действия приложения, новое окно, закрепить, закрыть.
* **Лаунчер** (`SUPER + Space` или кольцо): строка поиска, часто используемые, сетка всех приложений. Нечёткий поиск, стрелки, калькулятор (`=2+2`), команда в терминале (`>htop`), поиск в интернете.
* **Быстрые настройки** (клик по часам, `SUPER + N`): плитки Android 16 (интернет, Bluetooth, «Не беспокоить», ночной режим, тёмная тема, микрофон, «Без сна», запись экрана, скриншот, буфер обмена), толстые слайдеры громкости и яркости, плеер MPRIS и центр уведомлений над ними.
* **Уведомления**: карточки справа внизу с действиями, быстрым ответом и смахиванием.
* **Обзор** (`SUPER + TAB`), **буфер обмена** (`SUPER + V`, cliphist), **меню питания**, **экран блокировки** с часами как на Pixel, **OSD** громкости, **агент polkit** (окно пароля для LACT, NetworkManager и пересборки), **простой**: блокировка, выключение экрана и сон по таймерам.

### ⚙️ «Настройки» — вся система через GUI

Обычное окно (`SUPER + S`, ярлык «Настройки» в лаунчере) с разделами слева и цветными кружками, как на Pixel:

| Раздел | Что настраивается |
| :--- | :--- |
| Сеть и интернет | Wi‑Fi (поиск, пароль, забыть), Ethernet, проверка доступа, редактор соединений |
| Подключённые устройства | Bluetooth: сопряжение, подключение, батарея устройств |
| Экран | схема мониторов с перетаскиванием, разрешение, частота, масштаб, VRR, откат через 15 с; ночной режим |
| Звук | громкость, устройства вывода/ввода, громкость каждого приложения |
| Обои и стиль | обои (общие или свои для каждого монитора), **Wallpaper Engine** из мастерской Steam, шрифт всей системы, цвета из обоев или свой цвет, 8 стилей палитры, тёмная тема, значки |
| Рабочий стол и окна | панель задач, закреплённые, часы; скругления, отступы, рамка, прозрачность и размытие окон Hyprland |
| Быстрые настройки | какие плитки в шторке и в каком порядке, плеер, яркость |
| Уведомления | «Не беспокоить», угол и монитор, время показа, уведомления о скриншотах |
| Приложения | приложения по умолчанию (браузер, файлы, видео…), автозапуск |
| Клавиатура и мышь | раскладки и их переключение, повтор клавиш, чувствительность, ускорение, прокрутка, список сочетаний |
| Питание и блокировка | блокировка, отключение экрана и сон по бездействию |
| **Система** | часовой пояс и язык, службы (Bluetooth, печать, Docker, Sunshine, sched-ext, zram…), игры, **пакеты из nixpkgs и Flatpak с поиском**, порты брандмауэра, сборка мусора; кнопки «Применить», «Обновить систему», «Проверить сборку», откат на прошлое поколение |
| О системе | процессор, видеокарта, память, версия NixOS, поколение |

Всё, кроме раздела «Система», применяется сразу. Настройки оболочки лежат в `~/.local/state/pixel-shell/settings.json`, параметры Hyprland — в `~/.config/hypr/shell/*.lua` (их подключает `hyprland.lua`).

Раздел «Система» правит **`system.json`** в корне репозитория — его читает `modules/system/gui-settings.nix`. «Применить» собирает систему от пользователя и переключает через `pkexec` (пароль спросит окно polkit) — по сути `nixos-rebuild switch`, только с прогрессом и журналом прямо в окне. Файл можно править и руками.

### 🌌 Wallpaper Engine

«Настройки → Обои и стиль → Живые обои»: оболочка находит обои из мастерской Steam во всех библиотеках (родной Steam, Flatpak, дополнительные диски из `libraryfolders.vdf`), показывает превью и тип (сцена/видео/веб) и запускает `linux-wallpaperengine` на всех мониторах. Звук, громкость, FPS, масштабирование и пауза в полноэкранных играх — там же. Цвета палитры берутся из превью обоев. Для «сцен» нужен установленный в Steam сам Wallpaper Engine (его ресурсы).

## 🖥️ Мониторы и воркспейсы

Воркспейсы жёстко распределены по двум мониторам, поэтому всегда понятно, где какое приложение, и во время игры ничего не теряется. Раскладка задаётся в `hosts/nixos/host.nix`: из него генерируются стартовые режимы мониторов и правила воркспейсов для Hyprland (`hypr/host.lua`). Разрешение, частоту и расположение потом меняют в «Настройки → Экран».

**Основной монитор (LG Ultrawide, HDMI-A-1):**
* Воркспейсы **1–4** и игровой **5 (Gaming)**. Переключение: `SUPER + [1, 2, 3, 4, G]`.
* 🎮 На воркспейс **5** автоматически уезжают процессы с флагом `game`, лаунчеры (Lutris, Heroic, Bottles) и Gamescope. Всё, что открывается на нём, становится плавающим окном.

**Дополнительный монитор (Acer, HDMI-A-2):**
* Воркспейсы **6–9**. Переключение: `SUPER + [F1, F2, F3, F4]`.
* Приложения сами открываются на своих местах:
  * **6 (F1):** Discord
  * **7 (F2):** Telegram
  * **8 (F3):** YouTube Music
  * **9 (F4):** главное окно Steam

## 🖱️ Перетаскивание файлов между воркспейсами (`dndSpring`)

Модуль оболочки (`modules/shell/qml/modules/dnd`), который добавляет пружинящие воркспейсы, как в macOS:

* **Верхний край экрана.** Тащишь файл к верху — появляется ряд воркспейсов этого монитора. Задерживаешь файл над нужным — воркспейс открывается, а файл остаётся в руке, и его можно бросить в любое окно там. Пока просто ведёшь файл вдоль ряда, ничего не срабатывает.
* **Левый и правый края.** Держишь файл у края — лента окон прокручивается в эту сторону и разгоняется, чем дольше держишь.
* Если отпустить файл прямо над полоской, плагин его не принимает — источник ничего не копирует и не удаляет.

Скорость подстраивается числами в начале `DndSpring.qml`.

### 🗂 Воркспейсы
* **Переключение:** `SUPER + [1-4, G]` (основной монитор), `SUPER + [F1-F4]` (второй).

* **Соседние:** `SUPER + CTRL + ←/→` — листать воркспейсы текущего монитора, `SUPER + CTRL + ↓` — первый пустой.
* **Окно на соседний:** `SUPER + CTRL + SHIFT + ←/→` или колесо мыши с теми же клавишами.
* **Мышь:** колесо с зажатым `SUPER` или `SUPER + CTRL` листает воркспейсы.

## 📦 Как применить

> **Своя машина.** Всё железо лежит в `hosts/<имя>/`. Скопируйте `hosts/nixos` в папку с именем своего хоста, положите туда свой `hardware-configuration.nix` (`nixos-generate-config --show-hardware-config`), поправьте или очистите `disks.nix` и опишите мониторы, видеокарту и андервольт в `host.nix` (андервольт лучше выключить: `undervolt = null;` — смещение подбирается под конкретный процессор). В `flake.nix` поменяйте `username` (и `configDir`, если клонировали не в `~/nixos-config`). Собирать — `.#<имя папки>`.

Конфиг хранится в домашней папке как обычный git-репозиторий:

```bash
# 1. Клонируем
git clone https://github.com/deadinside28/nixos-config.git ~/nixos-config
cd ~/nixos-config

# 2. Обновляем lock-файл (по желанию)
nix flake update

# 3. Применяем
sudo nixos-rebuild switch --flake .#nixos
```

> Flakes видят только файлы, которые знает git. Новый модуль нужно добавить через `git add`, иначе при сборке его «не будет».

## ⚠️ Известные ограничения
* **Steam Remote Play на Wayland** может мигать и вылетать — это ошибка самого Steam. Надёжнее запускать стрим из сессии Gamescope или через Sunshine + Moonlight.
* **Wine-приложения** рисуют собственный диалог выбора файлов: к порталу Wine не подключается.
